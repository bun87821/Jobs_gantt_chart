# 專案時程追蹤（Jobs Gantt Chart）

單一 HTML 檔的專案時程追蹤網頁，不需安裝、不需伺服器，直接用瀏覽器打開 `index.html` 就能使用。

## 功能

- **專案時程管理**：記錄每個專案的開始日期與預計完成日期，並以甘特圖長條呈現。可標記狀態（進行中／已完成／暫停）。
- **每日執行紀錄**：每天輸入「今天在哪個專案做了什麼」，紀錄會立即以圓點顯示在甘特圖對應的日期上，滑鼠移過去即可看到內容。
- **週報檢視**：切換到「週報」分頁，可逐週瀏覽每天做了哪些事、目前還有哪些專案進行中，並一鍵複製成純文字週報。
- **資料備份**：資料儲存在瀏覽器 localStorage，可隨時匯出／匯入 JSON 備份檔。

## 使用方式

1. 用瀏覽器開啟 `index.html`（或部署到 GitHub Pages）。
2. 點「＋ 新增專案」建立專案，填入名稱、開始日期、預計完成日期。
3. 每天點「＋ 記錄今日進度」輸入當天執行的內容；也可以直接點甘特圖上的時間格子補記某一天的進度。
4. 週報時切到「週報」分頁，點「複製週報文字」即可貼到信件或文件中。

第一次開啟時可點「載入範例資料看看效果」快速了解畫面呈現。

## 注意事項

- 資料存在**目前這個瀏覽器**的 localStorage；換電腦或清除瀏覽資料前，請先用「匯出」下載 JSON 備份，再到新環境「匯入」。
- 支援亮色／深色模式，會跟隨系統設定自動切換。
